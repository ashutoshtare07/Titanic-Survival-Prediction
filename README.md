# Titanic-Survival-Prediction-Machine-Learning-Classification-Model
📖 Overview

This project predicts whether a passenger survived the Titanic disaster using machine learning. The dataset comes from the famous Kaggle Titanic Challenge
.
By analyzing passenger features like age, gender, class, and fare, the model learns survival patterns and makes accurate predictions.

⚙️ Tech Stack

Language: Python

Libraries: pandas, numpy, matplotlib, seaborn, scikit-learn

Algorithm: Random Forest 

🧠 Approach

Data Cleaning: Handled missing values, encoded categorical variables, and removed unnecessary columns.

EDA (Exploratory Data Analysis): Visualized relationships between survival rate and features like sex, age, class, etc.

Feature Engineering: Created new meaningful features.

Model Building: Trained multiple models and selected the one with the highest accuracy.

Evaluation: Achieved 82% accuracy on the test dataset.

📊 Results

Accuracy: 82%

Evaluation Metric: Accuracy Score

Feature Importance: Gender, Passenger Class, and Age had the most influence on survival.

📁 Dataset

Kaggle Titanic Dataset
